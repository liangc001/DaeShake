# 抓大鹅晃屏助手

这是一个 Windows 小工具。它在微信窗口的小程序客户区内模拟短促的左键拖动，贴近“拖动屏幕完成摇晃”的操作方式，不读取或修改游戏进程。

## 启动

开发调试时，在 PowerShell 中运行：

```powershell
py screen_shaker.py
```

也可以双击 `start.bat`。

要带到另一台电脑使用，先在当前电脑双击 `build.bat`。构建完成后，把 `dist\DaeShake.exe` 复制到另一台 Windows 电脑即可，不需要安装 Python。

## 使用

最简单的使用方式：

1. 在目标电脑打开微信和抓大鹅小程序，让微信保持在前台。
2. 启动 `DaeShake.exe`。
3. 直接按 `Ctrl+Alt+F8`，工具会自动使用当前前台窗口并晃动一次。

需要调整参数时，在工具中修改后仍按同一个快捷键即可。也可以点击“自动找抓大鹅”，再点击“晃一下”。

参数说明：

- 模式：`强力`提供默认的 200px/280ms 参数，手动调整滑块后自动切换为`自定义`。
- 拖动距离：每次向左右或上下移动的像素距离，默认 200px。
- 如果目标客户区放不下当前轨迹，工具会只对本次摇晃自动缩小距离，确保按下点和全部移动都留在窗口内。
- 持续时间：整段拖动轨迹的时间，与拖动距离共同决定摇晃速度。
- 预计平均速度：根据当前轨迹、距离、次数和持续时间实时计算。
- 摇晃策略：可选 `水平往返`、`垂直往返`、`顺时针圆形`、`逆时针圆形`、`八字轨迹`。
- 重复次数：只能选择偶数次 `2 / 4 / 6 / 8`，默认 2 次；对圆形和八字轨迹表示重复轨迹次数。
- 起点“顶部中心”：默认位置，位于微信客户区顶部中央，不会拖到标题栏。
- 顶部偏移：从客户区顶部向下的像素距离，默认 20px；用于避开微信上方工具栏。
- 输入方式：默认使用`自动`；如果鼠标会移动但抓大鹅没有反应，改为`兼容`后再试。选择会自动保存。
- 垂直方向会自动把运动中心下移一个拖动距离，保证向上拖动时仍留在顶部偏移以下。
- 连续使用垂直模式时，起点会在顶部中心附近的三条轨道间循环，避免小程序忽略完全相同的重复手势。
- 起点“客户区中心”：适合微信小程序位于窗口中央的情况。
- 起点“当前鼠标”：先把鼠标放到小程序画面上，再按快捷键触发，适合手动指定位置。
- 完成后恢复鼠标位置：默认开启，避免工具改变日常鼠标位置。

全局快捷键：

- `Ctrl+Alt+F7`：把当前前台窗口锁定为目标。
- `Ctrl+Alt+F8`：触发一次晃动。
- `Ctrl+Alt+F9`：立即释放鼠标并停止当前拖动。

目标窗口需要可见、未最小化。工具会暂时接管鼠标，按所选输入方式把鼠标放到拖动起点并按住左键发送闭合的屏幕坐标轨迹。轨迹中的每一步都有大小相同、方向相反的配对，位移在摇晃过程中自然抵消；绝对坐标注入不受系统鼠标速度和加速度设置影响，释放左键前不会追加归位动作，也不会强制修改窗口坐标。拖动异常超时时会自动释放左键。若“完成后恢复鼠标位置”开启，释放鼠标后只会把鼠标指针放回原位置。工具会检测目标窗口是否以更高权限运行，并给出明确提示；微信和工具保持相同权限级别时输入最可靠。
